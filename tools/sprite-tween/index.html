Sprite Tween

Load the start pose and the end pose. Each pixel slides toward a pixel of the same color, then snaps to the grid. Paint any frame that needs a correction. That frame stays, and the open frames around it rebuild.

Export two poses from Pixsplat as PNG at the same canvas size.

Pixsplat stays the drawing program. This page only fills the gap. A sprite strip is one horizontal PNG, frames left to right, for the game. The zip is one PNG per frame, for bringing the poses back into Pixsplat. Same colors travel. A color that exists on only one pose grows in or shrinks away. A move of N pixels needs about N − 1 in-betweens to land on every pixel along the way. Arrows change frame. Space plays. B pencil, E eraser, I pick. ⌘Z undoes. [ and ] zoom.
