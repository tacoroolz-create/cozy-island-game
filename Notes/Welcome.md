# Cozy Island Game — Notes

Design notes and worldbuilding for the game. Runtime files (code, assets,
`underworld.csv`, `CLAUDE.md`) stay in the project root; only notes live here.

## Sections

- **[[Characters]]** — NPC drafts, details, and conversation writing (`NeighborRewrite/`)
- **[[World]]** — world redesign, the temple/house/magic/unlock design notes, scope
- **[[Story]]** — story arcs (incl. the Hermes pass)
- **[[Holidays]]** — per-holiday outlines, `holiday_status.txt`, handoff doc
- **[[Art]]** — sprite map, sprite TODO, sprite update log
- **[[Systems]]** — items, gardening, general-store items
- **[[Reviews]]** — dated playtest/feedback reviews
- **[[Meta]]** — Claude wiring brief, how-to-play
